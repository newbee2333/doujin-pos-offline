## 1. 安装与离线准备

- [ ] 联网打开应用，能完成启动自检（不出现「当前环境不能营业」）
- [ ] 「离线准备完成」提示出现后才断网（若资源没缓存完就不该显示）
- [ ] 添加到主屏幕后，从主屏幕图标能独立打开（不是浏览器标签页外观）

## 2. 飞行模式冷启动

- [ ] 开启飞行模式，**完全关闭**应用进程后重新打开
- [ ] 商品图片能正常显示（图片来自 SQLite，不依赖网络缓存）
- [ ] 收款二维码能正常显示
- [ ] 所有必需路由都能进入（不只是已经打开过的页面）：
  - [ ] `/kiosk` 游客菜单
  - [ ] `/kiosk/cart` 购物车
  - [ ] `/kiosk/checkout` 结算
  - [ ] `/staff/checkout` 摊主收银
  - [ ] `/staff/pending` 待付款
  - [ ] `/staff/products` 商品
  - [ ] `/staff/events` 展会配置
  - [ ] `/staff/inventory` 库存
  - [ ] `/staff/orders` 订单
  - [ ] `/staff/reports` 报表
  - [ ] `/staff/backup` 备份
  - [ ] `/settings` 设置
  - [ ] `/preview` 预览

## 3. 游客下单 → 摊主收款

- [ ] 游客浏览、分类筛选、搜索、看详情、选规格
- [ ] 加入购物车、改数量、移除、看总额
- [ ] 提交订单 → 看到订单号、明细、币种、应付总额、付款说明、收款码
- [ ] 收款码断网可显示（**不是**动态支付码）
- [ ] 摊主 PIN 解锁 → 确认收款 → 库存正确扣减
- [ ] 零元订单：不要求扫码，摊主确认发放后扣库存、不生成收款记录

## 4. 异常订单类型

- [ ] 套装订单：成分库存正确扣减，套装商品本身不独立占库存
- [ ] 赠品：售价 0，默认仅摊主可添加
- [ ] 取消未付款订单：预留被释放，实际库存不变
- [ ] 整单退款：全额退款，可只部分实物返库，原订单状态变已退款
- [ ] 撤销误记：与退款分开，报表「纠错额」单列，钱箱口径正确
- [ ] 限购：合并套装成分一起计，超限被拒

## 5. 进程被杀 / 锁屏恢复

- [ ] 强制结束应用进程后重开：已提交数据仍在
- [ ] 未付款订单的**预留没有丢失**（库存表预留数不变）
- [ ] **不会**因为重新启动而重复下单或重复扣款
- [ ] 锁屏 / 切后台一段时间再回来：数据完整，游客购物车按规则处理
- [ ] 中途有 pending 订单时，重开后能在待付款列表找回

## 6. 文件往备（最关键）

- [ ] 平板导出 SQLite 到本地「文件」应用（不是只在浏览器下载列表里）
- [ ] 把文件传回电脑 / 新浏览器 Profile 导入
- [ ] 逐项比对（**不能只比总营业额**）：
  - [ ] 商品、规格、分类数量一致
  - [ ] 图片与收款码字节一致（资源 hash）
  - [ ] 订单金额、订单行数、订单号序列
  - [ ] 库存余额与流水
  - [ ] 收款 / 退款 / 纠错记录
  - [ ] 现金流水与收摊结算

## 7. 故障与恢复

- [ ] 导入损坏文件：明确报错，**原库不受影响**
- [ ] 导入未来 schema 的数据库：拒绝并提示更新应用，不降级不删库
- [ ] 用旧备份覆盖新数据：显著提示「新成交可能被覆盖」
- [ ] 导入过程中强杀应用：重启后能回到一个完整有效的库（旧库或新库之一）
- [ ] 收摊结算：有 pending 订单时阻止关闭；差额计算正确

## 8. 游客边界

- [ ] 刷新 / 返回 / 深链接**不能**让游客读到后台或他人订单
- [ ] 挂起后接待下一位：前一位的订单访问权限和购物车被清除，后台锁定
- [ ] 预览页不产生任何真实业务数据（订单数、库存不变）
- [ ] 两个标签页同时打开：只有一个可写实例，另一个提示「已在另一个窗口运行」
