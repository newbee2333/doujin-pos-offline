# 同人摊位电子菜单 · 使用说明书

> **在线使用**：https://d0a4166b6973444faaf7e2ef6e9724cd.app.workbuddy.link
> 构建与部署等**开发者文档**见 [docs/开发文档.md](docs/开发文档.md)。
给摊主（和帮摊的朋友）看的操作手册。按"摆摊前 → 摆摊中 → 收摊后"的时间线组织，遇到问题查最后一节。

> 这个系统**完全跑在你自己的设备上**：数据存在本机浏览器里，不联网也能用，没有任何服务器。好处是断网照样收钱；代价是**备份是你唯一的保险**，请务必看第 7 节。

---

## 1. 第一次使用

1. 打开应用（线上链接或本机地址）。
2. 首页会提示**建立新的空数据库**，点它。
3. 进入后台时要求**设置后台 PIN**：输入 4 位数字并确认。这个 PIN 保护后台和收款确认，**别用生日**，也别告诉帮摊以外的人。
4. 之后每次进后台都会要求**请输入后台 PIN**，输对才能进。

> 忘了 PIN：见第 9.2 节（数据不会丢，但有一步手工操作）。

---

## 2. 摆摊前的准备

### 2.1 建一场展会

后台 → **展会** → **新建展会**，填名称（如"冬季例大祭"）。

### 2.2 录入商品

后台 → **商品** → **新增商品**：

- **名称**：顾客看到的名字，尽量和实体一致
- **默认价格**：仅作填表参考，实际售价在展会里按场次设
- **类型**：普通商品（有库存）/ 套装（由其他商品组成）/ 无库存商品（如接单、免费无料）
- **分类**：新刊、既刊、亚克力、徽章、色纸、套装……可在设置里增删
- **封面图**：**强烈建议每件都传**。游客菜单靠封面认货，没有图会显示"无图片"占位。图片会自动压缩（最大边 1600px），放心传原图

商品建好后点**编辑**可以随时改。

### 2.3 把商品加进本场

后台 → **展会** → **全部加入本场**。然后在本场列表里逐行填：

- **本场价格**（可以和默认价不同）
- **库存**：本场带了多少个。套装会自动按组件库存计算可用数
- 如果勾选了"显示精确库存"，游客菜单会显示「剩 N」

### 2.4 配置支付方式

后台 → **展会** → 支付方式：

- **本场启用**：勾选这场要用的（如"现金"）。扫码方式必须先上传收款码，游客才能选它
- **模板启用**：不勾选的话，之后新建的展会不会带它
- **确认需输 PIN**（默认勾选）：
  - 勾着 → 游客下单后，摊主要输 PIN 才能确认收款
  - 取消勾选 → 游客下单后，摊主**直接点确认即可**
  - 判定按**游客下单时选的支付方式**算。例：给"现金"关掉 PIN，现场就不用反复输

### 2.5 开场

后台 → **展会**：

1. **检查开场条件**：价格、库存、至少一种可用支付方式齐了才会过
2. **开场**

开场后游客菜单才会接受下单。未开场时游客会看到"本场展会当前是草稿状态，暂时无法下单"。

### 2.6 用菜单预览检查效果

商品页和展会页都有**预览菜单效果**。里面可以切换三种画框（平板横屏 1180×820 / 平板竖屏 820×1180 / 手机 390×844），**画框里显示的就是真机布局**。摆摊前用它在 iPad 上过一遍，比现场发现排版问题强得多。预览模式不产生任何真实业务数据。

### 2.7 把它装成 iPad 上的"App"

用 Safari 打开线上链接 → 分享 → **添加到主屏幕**。之后从主屏幕图标进入，全屏显示，没有浏览器地址栏，也更适合游客操作。装好后**首次联网打开一次**让缓存就位，之后断网也能用。

## 3. 摆摊中：游客怎么用（自助菜单）

游客菜单是给顾客的界面，全程不需要 PIN：

1. **浏览**：按分类筛选或搜索。每张卡片是大封面 + 品名，右上角的小标签表示库存状态：
   - **剩 N**（开了"显示精确库存"时）/ **少量**：库存吃紧，抓紧买
   - **售罄**：整张卡片变灰并盖"售罄"章，不能加购
2. **加购**：点**＋ 加入**；已在购物车里则出现数量增减按钮
3. **购物车**：屏幕底部常驻一条（件数 + 合计），点**查看购物车**进详情。每行左侧有商品小图，方便核对"我到底加了哪个"
4. **结算**：**去结算** → 选支付方式 → **提交订单**
5. **付款**：跳到订单页，显示**订单号 #N** 和金额，按提示**把页面出示给摊主核对**，摊主在下一节的两条路径里收款

**闲置保护**：购物车里还有东西但 5 分钟没人操作，页面会提示"长时间无操作，购物车将在 N 秒后清空"，再过 30 秒没响应就清空回到菜单。点任意处即可继续使用。这是为了防止上一个顾客的遗留购物车混进下一单。

---

## 4. 摆摊中：摊主怎么收款

两条路径，对应两种售卖方式。

### 4.1 路径一：游客自助下单（推荐人多的时候用）

游客自己加购、提交订单（第 3 节），你这边会出现在：

后台 → **待付款**

每一行就是一笔等收款的订单：

1. **选择实际收款方式**（可以和游客选的不同，比如游客选了扫码但你现场收了现金）
2. 现金的话可点**按应付金额**自动填实收，或手工输入（自动算找零）
3. **确认已收款**（零元订单显示**确认发放**，比如免费无料）
4. 收错了就点**取消**，需确认（"摊主核实未收款"）

确认完订单进入已完成，库存同步扣减。

> 这一步要不要输 PIN，取决于游客所选支付方式上的**确认需输 PIN** 开关（见 2.4）。免 PIN 确认**不会**顺带解锁整个后台。

### 4.2 路径二：摊主收银台（推荐人少、或游客不想自己点的时候用）

后台 → **收银**：

1. 从商品网格点**＋ 加入**（和游客菜单同款大封面卡片）
2. 右侧调数量、看应付
3. **收款方式**选现金时输入实收，自动显示**找零**
4. **确认收款并完成** → 提示"已记录收款，找零 ¥N"，库存同步扣减

这条路径在后台里，本来就有 PIN 保护。

### 4.3 改价、取消

- **游客的订单还没确认**：在待付款页点**取消**，或让游客在订单页等摊主处理时直接操作
- **已经确认收款的**：后台 → **订单** 里可以发起更正/退款（记录会留痕，报表可查）

---

## 5. 摆摊中：库存与看数

- **库存**：每件商品的 初始 / 实际 / 预留 / 可用 四个数实时更新。套餐按组件库存算
- **订单**：所有订单及其状态（待付款 / 已完成 / 已取消）
- **报表**：按支付方式、商品维度的销售汇总，收摊前可用来对现金

---

## 6. 收摊

1. 先把**待付款**里的订单全部**确认已收款**或**取消**——还有未处理订单时**收摊会失败**，这是故意的（防止漏收款）
2. 后台 → **展会** → **收摊**
3. 收摊后首页会出现**立即导出**的提示——这就是第 7 节的备份，别点稍后

收摊后游客菜单不能再下单；数据全部保留，下次开场前可继续用或复用商品。

---

## 7. 备份与恢复（最重要的一节）

**所有数据只存在这台设备的浏览器里。** 清除浏览器数据、重装系统、设备丢失，数据就没了。唯一保险是导出备份文件。

- **导出**：后台 → **备份与恢复** → **导出 SQLite**，会下载一个 `.sqlite` 文件。**传到网盘或电脑上存一份**，别只留在 iPad 的下载文件夹里
- **何时导**：每天开场前一次、收摊后一次（应用超过 2 小时没备份会在首页提醒，超过 24 小时会强提醒）
- **恢复**：新设备或出事之后 → **备份与恢复** → **选择 SQLite 文件恢复**，选之前导出的文件即可，商品、订单、设置全部回来

换新 iPad 的标准流程：旧设备导出 → 新设备装应用 → 恢复 → 完成。

## 8. 常用设置

后台 → **设置**：

- **后台 PIN**：修改 PIN
- **库存展示**：是否在游客菜单显示精确库存（「剩 N」）。关掉则只在"少量/售罄"时提示
- **存储与离线状态**：查看本机数据库占用和离线可用性
- **备注**：给这台设备留个标记（如"主收银 iPad"），多设备时有用

## 9. 常见问题

### 9.1 游客点了"提交订单"白屏 / 卡住

旧版本的一个 bug（已修复）。如果还遇到：刷新页面（下拉刷新或重新打开），订单仍在"待付款"里，不会丢单。请把线上链接重新打开一次以获取新版本。

### 9.2 忘了后台 PIN

数据不会丢。用设备上**已经解锁的后台**进 设置 → 后台 PIN 重设；如果后台被锁住且 PIN 确实想不起来，需要重置数据库（会清数据）——**所以导出备份的习惯是救命稻草**。

### 9.3 收摊点不动

一定是有**待付款订单**没处理。去后台 → **待付款**，逐笔**确认已收款**或**取消**，再收摊。

### 9.4 游客菜单上商品是灰的

两种可能：库存为 0（显示"售罄"），或展会还没开场（游客侧会提示"暂时无法下单"）。去展会页确认状态，或去库存页核对数量。

### 9.5 断网了还能用吗

能。一切功能（下单、收款、改库存）都在本机完成。**备份导出需要网络**（要下载文件到本地），所以别等到断网才做第一次备份。

### 9.6 游客的购物车突然被清空了

5 分钟无操作的保护机制（见第 3 节末尾）。提示出现时点一下屏幕就能续命。

### 9.7 想在开场前检查菜单显示效果

用**预览菜单效果**（见 2.6），三种设备画框可切换，不会产生真实数据。

### 9.8 两台 iPad 能同时用吗

可以各开各的，但**数据不互通**（各自在本机）。建议固定一台作为收银/游客共用机，另一台只做帮摊查数；收摊后以那台的数据为准导出备份。多设备混写同一单目前不支持。

| 建展会 | 展会 → 新建展会 | 填名称 |
